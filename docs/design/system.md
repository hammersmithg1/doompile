# Doompile: бренд и интерфейсы

Версия 2 · 1 ноября 2026. Визуальный каталог: [preview.html](preview.html).

## Основа

Your digital pile of good intentions.

Doompile — личный сервис для себя и друзей: красивая бездонная воронка для ссылок, находок, цитат и мыслей, к которым мы совершенно точно вернёмся. Когда-нибудь.

Тон позитивный, стёбный и саркастичный. Уверенное преувеличение, дружеские подколы и шутки про бесконечное «на потом» приветствуются. Основная реплика — **Save it. Forget it.** Сохранять этот характер при новых экранах и текстах. Функциональные статусы сохранения, синхронизации и ошибок остаются точными и русскими.

Тёплая светлая тема и спокойная тёмная тема — полноценные варианты продукта. Кислотный лайм отмечает бренд и главное действие. Он не используется для длинного текста. Приглушённый зелёный обозначает вторичные акценты; тёплый красный — важность и действия, требующие внимания.

## Язык

- Брендовые реплики — английские, только из `packages/design/brand.json → copy`.
- Действия, подсказки, ошибки, настройки, разрешения ОС и подписи доступности — русские.
- Ключевые повторяемые интерфейсные тексты находятся в `brand.json → ui`.
- Названия Doompile, Safari, Google, iOS/macOS, форматы файлов и названия клавиш сохраняются.
- Цитаты и пользовательские данные не переводятся. Собственные сообщения приложения переводятся; технический ответ стороннего сервиса может дополнять русское объяснение.
- Новый английский слоган сначала получает роль и ключ в источнике. Для создания новой реплики не нужно отдельное разрешение; её связь с голосом бренда должна быть объяснима в изменении.

| Ключ | Где использовать |
| --- | --- |
| `tagline` | Описание бренда, сведения о приложении, метаданные |
| `motto` | Основной слоган: главный экран, боковая панель, подпись быстрого ввода |
| `later` | Вторичная реплика про откладывание |
| `capture`, `forget` | Две строки главного заголовка; вместе образуют `motto` |
| `saved` | Брендовая реплика после подтверждённого локального сохранения |
| `empty` | Первый вход и пустая коллекция |
| `cat`, `aside` | Дружеская саркастичная реплика персонажа |

Функциональное подтверждение всегда позволяет различить «сохранено на устройстве», «ожидает отправки» и «синхронизировано». Реплика `In the void.` не заменяет эти состояния и не обещает загрузку на сервер.

## Графика

- `mark.svg`: векторная версия чёрной дыры / воронки с падающими заметками и кольцом по краю. Стопка и конверт не используются как основной знак.
- `illustrations/app-icon-void.png`: общий коллажный мастер полноцветной app icon, созданный встроенным image_gen по референсу пользователя. Источник задаёт `brand.json → appIcon.artwork`. iOS/macOS, PWA и расширения получают PNG из этого мастера; отдельные версии вручную не рисуются.
- `mark-small.svg`: оптическая версия для панели браузера, строки меню и системных действий. Она проверяется в 16–32 px отдельно. Safari получает монохромный шаблон; Chromium/Firefox получают цветной знак на тёмной плашке, читаемый на обеих темах панели браузера.
- `halo.svg`: компактная подпись бренда. Изменение угла или штриха выполняется в этом исходнике.
- Название строится из контуров Sora ExtraBold. Исходный шрифт и OFL лежат в `packages/design/fonts`; системные шрифты остаются шрифтами интерфейса.
- Бездна / воронка — основной образ и символ накопления. Жёлто-лаймовое кольцо — узнаваемая подпись и край воронки. Кот — второстепенный персонаж. Корзина в интерфейсе означает удаление.
- Активные прозрачные иллюстрации `void`, `cat` созданы встроенным image_gen и хранятся в `packages/design/illustrations`. Воронка используется на главных и пустых экранах; исходник `pile.png` сохранён как архив версии 1 и не экспортируется в продукт. Промпты и происхождение — в [prompts.json](../../packages/design/illustrations/prompts.json).
- Новые иллюстрации сохраняют бумажный коллаж, чёрно-белую основу и лаймовый нимб. Не добавлять фоновой прямоугольник, текст внутри картинки или новую метафору основного знака.

## Пиктограммы

Авторитетный реестр: `packages/design/icons.json`, геометрия — Lucide с сохранённой лицензией. Смена главного знака не меняет значения управляющих пиктограмм поиска, закрепления, важности и других действий. Штрих 1.75 на сетке 24×24; размер и область нажатия задаются компонентом и платформой.

| Значение | Пиктограмма | Поведение |
| --- | --- | --- |
| Закрепление | `pin` | Удерживает запись в закреплённой группе |
| Важность | `flame` | Выделяет запись; не назначает срок или напоминание |
| Все записи | `layers` | Общая куча |
| Сохранение | `arrow-up` | Явно завершает быстрый ввод |
| Теги | `tag` | Поиск, создание и выбор тегов |
| Ссылка | `link2` | Источник либо ссылка на запись; различаются подписями действия |
| Удаление | `trash2` | Удаление с доступной отменой |

Звезда не означает закрепление. Состояние передаётся цветом, доступной подписью и `aria-pressed`, где применимо; переход к залитому альтернативному символу не должен менять значение.

React импортирует `packages/design/ui-icons`. Общий редактор использует `packages/design/icons`. Клиппер получает `DoompileDesign` при сборке. Apple-клиенты используют `DoompileSymbol` и общий `BrandAssets.xcassets`. Системные меню и специфические функции ОС могут использовать SF Symbols; соответствие основных действий задаёт `icons.json → native`.

## Общие компоненты и состояния

Платформы сохраняют нативную компоновку и жесты. Семантика и содержимое согласованы.

| Компонент | Обязательные состояния и правила |
| --- | --- |
| Быстрый ввод | Пустой, черновик, запись голоса, сохранение, ошибка. Сначала сохраняет локально. Раскрытие переносит текущий черновик. |
| Редактор | Создание и чтение различаются фокусом. Закрытие сохраняет непустой документ; ошибка оставляет возможность повторить. |
| Карточка источника | Источник/заголовок, сохранённая цитата, собственная мысль, метаданные. Цитата отделена от комментария. |
| Теги | Несколько выбранных значений, поиск, создание нового, удаление выбранного. Предпочтителен общий сценарий поиска и выбора; текстовый ввод через запятую — компактный вариант Share Sheet. |
| Закрепление/важность | Общие символы и подписи во всех точках входа, включая свайп и контекстное меню. |
| Пустая коллекция | `void`, брендовый заголовок `motto`, русский текст о ссылках/находках/мыслях, доступный ввод. |
| Пустой поиск | Явное сообщение «Ничего не найдено», возможность изменить запрос. Оно не означает потерю сохранённых данных. |
| Сохранение/синхронизация | Отдельно подтверждаются локальная запись, очередь, доставка и ошибка. Юмор не скрывает статус. |

## Как изменять систему

1. Найти существующий текст, токен, символ или компонент. Повторяемая роль использует общий источник.
2. Изменить `brand.json`, `tokens.json`, `icons.json`, исходный SVG или иллюстрацию. Для нового символа можно выполнить `node scripts/add-design-icon.mjs LockKeyhole --label 'Доступ'`; при необходимости добавить соответствие SF Symbol в `icons.json → native`.
3. Выполнить `npm run shared:generate`. Это обновляет CSS/Swift, React/DOM-иконки, asset catalog, app icons, PWA и Action-иконки. Сгенерированные файлы не правятся вручную.
4. Обновить потребителей. Клиппер собирать в отдельный каталог при работающем расширении: `node extensions/clipper/build.mjs --out-dir /tmp/doompile-design-clipper`.
5. Выполнить `npm run shared:check`, затем проверки затронутой платформы. `npm run verify` включает проверку системы; native CI также вызывает `shared:check`.
6. Открыть [preview.html](preview.html), проверить обе темы, 16/32 px, интерфейсный набор и прозрачность иллюстраций. Для изменения компонента приложить актуальные экраны desktop/mobile и проверить пустое, заполненное, выбранное, отключённое и ошибочное состояния, которые оно поддерживает.
7. Записать существенное изменение языка или визуального правила в [CHANGELOG.md](CHANGELOG.md). Новая версия системы нужна для изменения правил; исправление экспорта или локального текста не требует её повышения.

### Автоматические границы

`design:check` сравнивает 1:1 с исходниками все экспортируемые файлы, включая PNG и общие нативные ресурсы. Проверка правил отслеживает английские статические подписи в JSX/Swift и DOM, прямые импорты сторонних пиктограмм, возвращение звезды для закрепления, нарушенные нативные соответствия и отсутствующие PWA-иконки. Список технических имён задан явно.

Проверка не оценивает качество композиции, динамические серверные сообщения или понятность жестов. Для таких изменений нужен просмотр реальных экранов. Сбой проверки исправляется в источнике, потребителе или точном обоснованном правиле; общие отключения проверки и широкие исключения не добавляются.

### Окружение

Для генерации: Node.js из `package.json`, `npm ci`; зависимости закреплены в lock-файле. ENV-переменные, сеть, секреты и установленный системный шрифт для генерации и проверки не нужны. Apple-сборка требует macOS/Xcode. Повторная AI-генерация иллюстраций выполняется отдельно; обычная сборка использует сохранённые PNG и не обращается к AI-сервису.
