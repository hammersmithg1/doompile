# Doompile · Save it. Forget it. · 1 ноября 2026

Система v2: [правила](../../design/system.md), [каталог](../../design/preview.html).

## Что изменилось

- Возвращён позитивный, дружеский и саркастичный тон личного сервиса: Save it. Forget it.; Good ideas. Deep down.; Great things. Someday. Maybe.
- Основной знак — бездонная воронка с падающими заметками и узнаваемым жёлто-лаймовым кольцом.
- Новый коллажный мастер app icon создан встроенным image_gen по референсу пользователя: `packages/design/illustrations/app-icon-void.png`. Промпт и параметры сохранены рядом.
- 16/32 px favicon и монохромные системные знаки используют упрощённую векторную воронку. Все размеры iOS/macOS, PWA, Action Extension и расширений экспортируются из общей системы.
- На пустых экранах и странице входа используется воронка. Стопка v1 остаётся архивным исходником и не экспортируется в продукт.
- Функциональные тексты, кнопки и статусы остаются русскими. Значения управляющих пиктограмм не менялись.
- В iOS большой набор модификаторов главного экрана разделён на вычисляемые представления: это устранило ограничение времени проверки типов SwiftUI, сохранив обработчики и сценарии.

## Проверки

- `npm run shared:generate` и `npm run shared:check`: 236 экспортов, проверка языка, пиктограмм, совпадения двух строк заголовка с общим motto и отсутствия активной стопки v1 — проходят.
- `npm run typecheck` — проходит.
- iOS Simulator: приложение и расширения собираются с `CODE_SIGNING_ALLOWED=NO`.
- macOS: приложение и Safari Extension собираются с `CODE_SIGNING_ALLOWED=NO`.
- Desktop/mobile web: пустое и заполненное состояния, две темы, desktop/mobile страница входа. API и аккаунт изолированы тестовыми ответами, горизонтального переполнения нет.
- Визуально проверены полноцветная иконка, малые размеры и монохромный знак; каталог открыт в обеих темах.
