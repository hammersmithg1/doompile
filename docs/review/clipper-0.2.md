# Web Clipper 0.2 — проверка правок

- Компактная карточка с цитатой и комментарием, раскрываемые настройки, изоляция шрифтов страницы.
- Изменены размеры html/body popup: обе ширины 360 px, горизонтального переполнения нет.
- Escape закрывает даже при фокусе внутри закрытого Shadow DOM; Command+Enter сохраняет и закрывает форму.
- Подтверждение локальной очереди отделено от подтверждения сервера. Receipt-запрос удерживает событие фоновой страницы до завершения отправки в Safari.
- Предупреждение на toolbar означает очередь; popup показывает названия, ошибки и повторную отправку, настройки позволяют проверить настоящий notes API.
- Для текстового выделения не показывается таймкод фонового видео страницы.
- Иконки со сглаживанием и прозрачным фоном; отдельные монохромные toolbar PNG 16/19/32/38/64/128.

18 тестов клиппера проходят. Локальная macOS-сборка с расширением проходит. Сборки Chromium/Firefox/Safari 0.2.0 созданы.

UI проверен в in-app browser на изолированной странице с Georgia и фоновым видео: компактный/развёрнутый вид, сохранение комментария при раскрытии, Escape и закрытие после сохранения. Цитата и комментарий действительно возвращаются через оригинальные API-обработчики заметок, использующие отдельную временную SQLite. Extension API в этом UI-стенде заменён тестовым адаптером; очередь и авторизация проверяются отдельно VM-тестами background.js. Реальную установленную Safari Extension не переключали и разрешения Safari не меняли. Окончательный рендер toolbar и popup в Safari требует Reload и обновления исходной страницы пользователем.
