# Clipper 0.3.1 — обмен с содержимым страницы

Симптом: после инъекции files вызов tabs.sendMessage разрешается без ответа; окно расширения показывает «Аннотация не ответила» и переключается на обычную заметку. Точная причина сбоя канала в Safari без его отладчика не установлена. Зависимость от этого канала устранена для всех трёх команд страницы.

- Вызов dispatch в изолированном мире расширения возвращает данные через InjectionResult.result. Скрипты не переносятся в MAIN world; разрешения не расширяются.
- Проверяются ошибки исполнения, включая ошибки в успешно разрешённом executeScript. Целевой frameId задан явно, а при ошибке вложенного фрейма остаётся переход к frame 0.
- Регрессионный интеграционный тест загружает реальный core.js и content.js в отдельный VM-контекст; tabs.sendMessage возвращает undefined, а чтение настоящего заголовка, URL и выделения через новый мост проходит.
- Проверены получение статьи, пропущенный запуск скрипта, ошибки исполнения и переход из iframe.
- 41 тест расширения прошёл. Собраны Safari/Chromium/Firefox и Mac-приложение со встроенным расширением 0.3.1.

Физическое воспроизведение в пользовательском Safari недоступно через текущие инструменты. Проверка покрывает программный сценарий отсутствующего ответа; проверка на реальной странице Safari остаётся необходимой.
