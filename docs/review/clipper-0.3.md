# Clipper 0.3.0 — проверка

- По значку сразу открывается поле заметки, включая состояние без подключения. Настройки — только через шестерёнку. Текст сохраняется при переключении настроек.
- Контекстное меню содержит единый пункт «Сохранить в Doompile» для страницы, выделения, ссылки, картинки и видео. При выделении текста внутри ссылки приоритет остаётся у цитаты.
- Компактная карточка не дублирует цитату; оригинал подсвечен через CSS Highlight с резервной подсветкой прямоугольниками. Карточка с абсолютными координатами находится под выделением. В браузерном тесте прокрутка на 216 px переместила и текст, и карточку на 216 px.
- На изолированном стенде с реальными обработчиками Next.js API сохранены цитата, комментарий и текст статьи (168 символов); карточка закрылась после сохранения. Отдельно проверено сохранение из popup с подтверждением и очисткой поля. База стенда находится в /tmp; пользовательские данные не менялись.
- Подтверждение доставки находится в настоящем popup расширения. Запрос action.openPopup и отказ браузера проверены тестом: отказ не теряет клип и его статус. Автоматическое открытие реального Safari popup физически не проверено; статус остаётся при следующем нажатии на значок.
- «Добавить текстовую копию статьи» добавляет plain text при сохранении заметки, максимум 250 000 символов, без оформления и ресурсов. Подсказка указывает, где читать результат; статус доставки показывает размер текста.
- 36 тестов расширения прошли. Сборки Safari/Chromium/Firefox и Mac-приложения с Safari Extension 0.3.0 успешны.
