# Clipper 0.4.0 — чатовый ввод

- Компактная аннотация: только поле, разворот и отправка. В toolbar-popup дополнительно доступна шестерёнка. Удалены заголовок, крестик и копия исходной цитаты в обоих режимах.
- Кликаут, потеря фокуса окна и Escape удаляют редактор, его обработчики и подсветку. Повторное открытие начинает пустой ввод; в браузере сценарий проверен после набора текста.
- Развёрнутый режим использует Tiptap с той же базовой схемой, форматированием и компоновкой, что веб. После закрытия компактного ввода открыт пустой расширенный редактор; сохранены жирный абзац и чеклист. Реальный Next.js API в изолированной базе подтвердил body с blockquote, bold mark и taskList. Цитата остаётся в данных заметки, но не дублируется на экране редактора.
- Общий composer используется и на странице, и в popup. Компактный код со стилями — 15 KB, rich-editor — 443 KB и загружается только по развороту.
- После отправки появляется отдельное подтверждение 230 px шириной с одним статусом. Редактор заново не открывается. Получение серверного подтверждения меняет статус с очереди на «Отправлено». Таймер — 2200 ms, затем скрытие и закрытие окна.
- 45 тестов прошли, включая очистку обработчиков при кликауте/blur, передачу rich JSON и отдельного source title, быстрые подтверждения и восстановление стандартного popup.
- Собраны Safari, Chromium, Firefox и Mac-приложение со встроенным Safari Extension.

Скриншоты: clipper-0.4-compact.jpg, clipper-0.4-expanded.jpg, clipper-0.4-receipt.jpg. Браузерный стенд использует настоящие JS-бандлы и API, данные записаны только в /tmp. Автоматическое открытие/закрытие настоящего Safari popup требует проверки на пользовательском Safari; в стенде проверен его UI, а управление browser action покрыто тестами.
