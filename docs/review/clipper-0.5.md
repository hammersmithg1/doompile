# Clipper 0.5.0 — офлайн PDF

- В компактном вводе проверены огонёк и переключатель «Сохранить офлайн». Без выделения отображается «Сохранить в Doompile…»; ширина toolbar popup — 520 px, подтверждения со ссылкой — 300 px.
- В браузерном стенде создан PDF из реальной DOM-копии страницы с ленивой PNG-картинкой и SVG-диаграммой. Настоящий Next.js API добавил файл к заметке. Конвертация — локальный Gotenberg с выключенными JS и сетевыми запросами Chromium. Исходная пользовательская БД не менялась.
- Отдельно создан и отрендерен пятистраничный A4 PDF; первая и последняя страницы проверены визуально. Иллюстрации встроены, переносы текста и поля корректны. Проверочный файл находится только в /tmp.
- 46 тестов расширения прошли, включая повтор PDF после ошибки и ссылку на уже сохранённую заметку. 38 тестов core/server/client прошли, включая идемпотентность PDF, сохранение одновременных правок, недоступный конвертер, приватные адреса и локальный кэш. TypeScript-проверка веба успешна.
- Собраны три браузерных пакета и Mac-приложение. В настоящий пользовательский Safari автоматический popup не запускался.

Тестовый PDF-сервис оставлен работающим локально на 127.0.0.1:3003 для дальнейшего использования. Web production Compose подключает тот же сервис. Кэш PDF для чтения без сети заполняется после синхронизации веб-приложения; простое сохранение в расширении не может записать кэш другого origin без запуска веба.
