# Clipper 0.6.0 — список чтения вместо собственного архива

- Удалены HTML-снимки, прокрутка, загрузка изображений, Readability из бандла, серверная конвертация PDF, специальный кэш PDF и Docker-сервис. Уже сохранённые заметки/вложения не удаляются. Локальный PDF-контейнер остановлен и удалён.
- Галочка «В список чтения» использует native messaging в Safari (Mac: NSSharingService, iOS: SSReadingList) и readingList API в Chromium. Firefox сохраняет заметки без недоступной галочки. Safari из временной папки без нативного обработчика показывает предупреждение.
- В Doompile остаётся исходный URL, цитата и комментарий. Прямого перехода к офлайн-копии браузера нет; список открывается в самом браузере. Автоматический офлайн в Safari — отдельная настройка.
- Заметка сначала сохраняется в локальную очередь. Ошибка списка чтения не теряет её и отображается в подтверждении. Старые PDF-задания больше не выполняются, серверные заметки из них остаются сохранены.
- 48 тестов расширения прошли. Проверены Chrome dedup, native messaging, отказ native handler без потери заметки и прекращение старых PDF-заданий.
- Mac-приложение и iOS Simulator со встроенным расширением собраны. Фактическое добавление в пользовательский Reading List не выполнялось: требуется проверка установленного расширения на Mac/iPhone.
