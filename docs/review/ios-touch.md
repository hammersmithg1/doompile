# iPhone touch update · 31 октября 2026

iOS приведён к спокойной светлой палитре веб-десктопа: тёплый фон, светлые карточки, тонкие границы, лайм для основных действий и красный для важного. Шапки на главном экране нет.

- Свайп влево по заметке открывает избранное, важность и удаление; полное случайное смахивание не удаляет запись.
- Боковое меню открывается от левого края и закрывается обратным жестом. Поиск и настройки находятся внутри меню.
- Быстрый ввод скрывает клавиатуру по тапу вне поля и сохраняет черновик. Повторный тап возвращает фокус.
- Микрофон начинает запись прямо на главном экране. Остановка сохраняет отдельную голосовую заметку, текстовый черновик остаётся независимо.
- Редактор использует общий с вебом блочный документ. Отдельного поля заголовка, верхней панели форматирования и нижних переключателей больше нет. Заголовок для списка выводится из документа.
- Новая заметка сразу получает фокус; существующая открывается без клавиатуры. Теги, звёздочка, отметка важности и закрытие компактно расположены над документом.
- Горизонтальная панель инструментов следует верхней границе клавиатуры. В ней чеклист, фото, файл, голос, форматирование, списки, отступы, ссылки, упоминания, таблицы, рисунок и история. В таблице дополнительно доступны строки и столбцы. Сохранение и скрытие клавиатуры остаются на месте при прокрутке инструментов.
- Запись внутри редактора заменяется аудиоблоком в той же позиции. Сохранение завершает активную запись; при ошибке записи файла исходное аудио остаётся для повторной попытки.

Исправлено падение при закрытии редактора: публикация готовности WebKit больше не происходит синхронно во время удаления SwiftUI-графа.

Проверено: Xcode 26.2, отдельный iPhone 17 Pro с iOS 26.2; все 5 UI-сценариев проходят. Общие модели — 19 Swift-тестов. Общий редактор — 72 браузерные проверки до финального расширения команд и ещё 6 проверок мобильных команд в Chromium/WebKit на итоговом снимке. TypeScript и сборка приложения с Share/Safari Extensions проходят. Микрофон проверялся в симуляторе; физический iPhone в этой сессии не использовался.

UI-тесты добавлены в iOS workflow. Подписанная доставка этой версии выполняется локально с ключами из setec; постоянный доступ GitHub Actions к setec — отдельная настройка.
