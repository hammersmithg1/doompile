# macOS: фоновый режим и автозапуск

1 ноября 2026.

В «Настройки → Фоновый режим» добавлены независимые галочки «Сворачивать в Dock» и «Показывать в строке меню». Они сохраняются на этом Mac и по умолчанию выключены. Первая определяет, остаётся ли приложение в Dock после закрытия всех обычных окон; открытые основное окно и настройки сохраняют обычное поведение macOS. Панель быстрой заметки не добавляет значок в Dock.

| Dock | Строка меню | После закрытия окон |
| --- | --- | --- |
| Выключено | Выключено | Без значков, вызов заметки по горячей клавише |
| Включено | Выключено | Только Dock |
| Выключено | Включено | Только строка меню |
| Включено | Включено | Оба значка |

Строка меню использует общий оптический брендовый знак `dp-mark`: монохромную воронку из `packages/design/mark-small.svg`. В собранном `Assets.car` проверено наличие шаблонных растров и векторного ресурса этого знака.

«Запускать при входе в систему» использует [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp). Состояние берётся из macOS, а ошибки регистрации и ожидание разрешения отображаются в настройках. Разрешение можно открыть в системных настройках. Автозапуск не включается без действия пользователя. События входа и запуска службы оставляют основное окно скрытым; Finder, Spotlight и меню позволяют снова его открыть. Сервисы захвата, синхронизации, обновлений и наблюдение за аккаунтом принадлежат делегату приложения и не зависят от существования окна или значка строки меню.

Проверено:

- Debug-сборка Xcode для macOS, локальный `.app` скопирован в `apps/macos/dist/Doompile.app` и подписан ad-hoc. `codesign --verify --deep --strict` проходит.
- `bash apps/macos/scripts/test.sh`: 18 Swift-тестов, включая 8 проверок фонового режима, восстановления окон, независимости настроек, событий запуска и ошибок регистрации автозапуска; также выполнены Python-проверки конфигурации обновлений из этого скрипта.
- `npm run design:check`: 236 экспортов и правила дизайна проходят.
- В Debug и Release plist установлен `LSUIElement`; новые исходники включены в сгенерированный проект Xcode.
