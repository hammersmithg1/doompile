# Мобильный веб · соответствие актуальному iOS · 31 октября 2026

Основание: просмотрены чаты «iOS Апп», «Общее Десктоп», «Переработать редактор заметок», актуальные исходники и скриншоты iOS из второго и третьего раундов. Старые стартовые макеты не использованы как текущая спецификация. Работа выполнена поверх незакоммиченных изменений остальных чатов; нативные приложения и общий формат документа не изменялись.

## Изменения

- Для экранов до 760 px: главный экран без шапки, компактный ввод с плюсом и микрофоном, спокойное пустое состояние. Enter на экранной клавиатуре добавляет строку; сохранение — явной кнопкой. Desktop Enter сохраняет прежнее поведение.
- Свайп от левого края открывает боковую панель с поиском и настройками. Скрытая панель и фон открытой панели исключены из последовательности доступности. Тап по ленте снимает фокус быстрого ввода.
- Действия заметки раскрываются горизонтальным свайпом: закрепление, важность и удаление с отменой. Одновременно раскрыта одна строка. Вертикальный жест остаётся прокруткой. Действия работают и у важных карточек. Контекстное меню сохранено.
- Мобильный редактор использует тот же документ и автосохранение, что desktop web. Новая заметка получает фокус, существующая открывается для чтения без автоматического вызова клавиатуры. Закрытие использует существующее ожидание записи и оставляет редактор открытым при ошибке.
- Теги, закрепление, важность и закрытие находятся в компактной шапке. Теги можно искать, добавлять, удалять и явно закрывать выбор. Создание тега из боковой панели не создаёт пустую заметку; каталог пустых тегов хранится локально, как на iOS.
- Прокручиваемая нижняя панель открывает общие команды редактора: чеклист, тип блока, цвет, форматирование, действия блока, фото, файл, голос, рисунок и undo. Справа — скрытие клавиатуры. Код редактора, загрузка файлов и запись голоса повторно не реализуются.
- Высота оболочки и нижняя панель следуют за `visualViewport` Safari, включая смещение окна при фокусе. При pinch zoom приложение не меняет раскладку; safe areas учитываются. Инструменты находятся вне прокручиваемого документа.
- Desktop-разметка важных карточек сохранена; мобильные обёртки жестов там не используются. Нативные Swift-клиенты не затрагивались.

## Проверки

`npx playwright test -c apps/web/playwright.mobile.config.ts`: **5 сценариев проходят** (4 iPhone WebKit, 1 desktop Chromium). Несоответствующие платформе сценарии пропускаются. API подменён тестовыми данными; настоящие заметки пользователя не менялись.

Проверены быстрый черновик и Enter, фокус новой заметки, команда чеклиста, панель при уменьшении viewport, сохранение при закрытии, вертикальный/горизонтальный жест, закрытие/повторное раскрытие действий, закрепление, важность, удаление/undo, поиск в боковой панели, каталог тегов после reload, добавление/удаление тегов из шапки, светлая/тёмная отрисовка и сохранение desktop-сценария.

`npm test`: **140 модульных тестов проходят** (76 приложения/редактора + 64 клиппера). TypeScript веба и изолированная production-сборка (`DOOMPILE_MOBILE_TEST=1 npm run build`) проходят.

Публикация на удалённый сервер не выполнялась.
