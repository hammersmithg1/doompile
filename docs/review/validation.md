## Адреса заметок и кроссплатформенные диплинки

Добавлен единый путь `/notes/<uuid>`, canonical URL helpers и прямой Next.js-маршрут. Серверная страница не раскрывает заголовок или содержимое приватной заметки.

iOS/macOS используют общий Foundation-парсер NoteLink: проверяют UUID, разрешённый origin, схему и путь; принимают custom URL и NSUserActivityTypeBrowsingWeb. Кэш открывается сразу, отсутствующая запись ожидает sync; после неуспеха показывается сообщение. Перед переключением работают зарегистрированные сохранения открытых редакторов, включая текущий WKWebView snapshot. Копирование ссылки добавлено в оба нативных редактора и меню.

Домен передаётся из GitHub variables, extensions не получают associated-domains, без домена существующая signing capability не меняется. При появлении домена потребуется включить capability, обновить профиль и установить новую подписанную сборку. Физическая ассоциация Apple/CDN пока не проверялась — домен пользователь выберет позже.

## Архитектурная переработка

- Веб хранит отдельные записи IndexedDB, мигрирует прежний snapshot и координирует вкладки. Ошибка одной операции не останавливает оставшуюся очередь/pull; ошибки видны в настройках.
- Нативное хранение переведено на SQLite с транзакциями и индексом изменений. Legacy `notes.json` импортируется атомарно и остаётся неизменной резервной копией. Тест на 2000 заметках подтверждает: после первой загрузки одно сохранение декодирует одну изменённую запись; изменения другого соединения тоже обновляются по одной записи. Share/Action отправляют только очередь без чтения/скачивания всей коллекции.
- Неизвестные блоки/inline/marks показывают «Ошибка отрисовки» и сохраняют raw JSON при редактировании соседнего текста. Проверены повторная загрузка и сохранение неизвестных атрибутов; обычные inline clipboard slices не превращаются в error blocks. Конфликты остаются отдельными копиями, без автоматического слияния.
- Stable upload UUID и долговечный checkpoint исключают дубли файлов/ложный конфликт при потере ответа. Проверены реальные API uploads/повторы и сохранение пользовательского ввода во время checkpoint.
- Общие JSON-контракты и дизайн-токены генерируют TS/CSS/Swift. Веб разделён на quick composer, settings, editor model и оболочку. Единый CI gate включает web/UI/iOS/macOS; подготовлены signed/notarized Mac ZIP и post-deploy readiness.
- `npm run verify`: typecheck, 97 TS/JS tests + 64 clipper tests, 7 infra/backup tests, обе JS-сборки и production webpack build — успешно.
- Swift core: 32 теста успешно, включая миграцию и 2000 записей; Mac behavior: 10 тестов успешно. Unsigned macOS build и отдельная проверка типов iOS/Share проходят.
- Playwright корректно собирает 176 editor cases, 14 mobile-web cases и 18 clipper cases. Выполнение UI не состоялось: автоматическая проверка разрешения на запуск вне sandbox завершалась по таймауту, в том числе после явного разрешения пользователя. Это не считается успешной UI-проверкой.
- Полная iOS-сборка в sandbox останавливается на asset catalog из-за недоступного CoreSimulator, а не подтверждает полноценную сборку. Подпись/TestFlight/notarization, физические устройства и реальный production deploy в этой переработке не запускались.
